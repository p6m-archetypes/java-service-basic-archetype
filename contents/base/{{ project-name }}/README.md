# {{ project_title }}

Basic service generated by `java-service-basic-archetype`. A minimal long-lived
Spring Boot HTTP server with platform plumbing (observability, health, CI/CD,
deployment manifests) but no domain logic and no resource dependencies.

## Build

```bash
mvn verify
```

## Run

```bash
cd {{ project-name }}-server
mvn spring-boot:run
```

Service starts on port `{{ service_port }}`, management on `{{ management_port }}`.

## Endpoints

| Method | Port | Path | Description |
|--------|------|------|-------------|
| GET | `{{ service_port }}` | `/` | Service identity — `{"service":"{{ project-name }}","status":"ok"}` |
| GET | `{{ management_port }}` | `/health/readiness` | Readiness probe |
| GET | `{{ management_port }}` | `/health/liveness` | Liveness probe |
| GET | `{{ management_port }}` | `/metrics` | Prometheus metrics |
